A Python program — standard library only, no network — that writes one line to /output/entry.txt: the 3 a.m. text a smart fridge sends its owner about the missing cake. The line is 128 characters, inside the competition's gate of 1 to 140 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
